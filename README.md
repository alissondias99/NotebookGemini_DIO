# NotebookGemini_DIO
# 🧠 A Matemática por Trás das Inteligências Artificiais

Projeto desenvolvido como parte de um desafio da **DIO**, utilizando o [Gemini Notebook](https://notebook.google.com/) para criar uma base de conhecimento e explorar conceitos matemáticos fundamentais que sustentam a Inteligência Artificial.

🔗 **[Acessar o Notebook do Projeto](https://notebook.google.com/notebook/ea96b731-94a1-4595-8086-a8b414bf0e71)**

## 🎯 Por que este tema?
A matemática que faz a Inteligência Artificial funcionar é frequentemente vista como um tema complexo e desafiador. Escolhi esse assunto pois é uma curiosidade que tenho há bastante tempo: entender como essas tecnologias realmente operam "por baixo dos panos". Este projeto foi a oportunidade ideal para estruturar esse aprendizado.

## ❓ Questões Exploradas no Notebook
Durante a construção da base de conhecimento no Gemini Notebook, levantei as seguintes questões para análise, utilizando fontes e documentos específicos:

- **O que é Álgebra Linear?**
  - *Base de conhecimento:* Fontes de 1 a 6.
  
- **Como a Álgebra Linear é usada em Redes Neurais?**
  - *Base de conhecimento:* Fontes todas as fontes carregadas, exceto a 5.

## 🛠️ Ferramentas Utilizadas
- **Gemini Notebook (NotebookLM):** Para curadoria das fontes, leitura de documentos e extração de respostas embasadas.
- **DIO:** Plataforma de educação em tecnologia responsável pela proposta do projeto.
